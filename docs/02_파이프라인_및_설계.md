> 상세 설명서의 3절, 4절, 5절, 6절. 절 번호는 원본 그대로이고, 요약은 [README](../README.md)에 있습니다. 경로는 저장소 루트 기준입니다.

## 3. 파이프라인

1. **조각 분할**
   - 정확히 같은 행은 지운다.
   - 시간 간격이 0.5초를 넘거나 0 이하이면 새 조각을 시작한다.
   - 정상 599조각, 이상 21조각이 나온다.
   - 모든 학습/시험 분할은 윈도우를 자르기 **전에** 조각 단위로 한다. 겹치는 윈도우가 분할 경계를 넘어 새지 않는다.
2. **윈도우 (조각 길이에 맞춤)**
   - 24행 이상 조각은 24행 윈도우, 16~23행은 16행, 8~15행은 8행 윈도우를 쓴다. stride는 4다.
   - 윈도우 길이마다 따로 학습한다.
   - 8행 미만 조각은 판정하지 않고, 시간상 가장 가까운 판정 조각의 결과를 따른다.
3. **9특징**
   - 진동: 상부/하부 RMS, 상부/하부 피크, 합 RMS, 차 RMS.
   - 전류: 0.6Hz 사인 맞춤으로 구한 중심선, 진폭, 왜곡(잔차비).
   - 맞춤 전에 4σ 넘는 1~2개 샘플을 보정한다.
   - 상하부 상관은 저부하 정상 구간에서 부호가 뒤집혀 오경보를 만들었기 때문에 뺐다.
4. **두 관점**
   - 통합 관점: 9특징 강건 마할라노비스(MCD).
   - 전류 관점: 전류 3특징 MCD. 9특징 안에서는 전류 변화가 진동 6특징에 묻히기 때문에 따로 둔다.
5. **보정**
   - 정상 학습 조각을 5겹으로 나눠, 각 조각을 그 조각을 보지 않은 모델로 채점한다(OOF).
   - 관점별 점수를 정상 백분위로 바꾸고 max로 합친다.
   - 주의 = OOF q95, 경고 = OOF q99. 목표 오경보율은 1%다.
6. **견고한 보정 (라벨 오염 대비)**
   - 정상 라벨에 고장이 섞여 있으면 q99 임계값이 끌려 올라가 같은 고장을 못 잡게 된다.
   - 그래서 OOF 점수(로그)의 강건 z가 3.5를 넘는 학습 조각은 임계값 계산에서 뺀다.
   - 지금 정상 데이터에서는 한 조각도 빠지지 않는다(비용 0). 오염 2~5%까지는 탐지가 유지된다(7.6절).
7. **추세 규칙 (현장 운용)**
   - 엄격 단일(q99.7) OR EWMA(λ=0.2)이고, 정상 OOF 시계열에서 함께 1%로 맞췄다.
8. **진단**
   - 진동 전용 MCD와 전류 전용 MCD의 카이제곱 꼬리확률을 비교한다.
   - 둘 다 1e-3보다 작으면 복합형이다.

## 4. 설계 결정: 채택한 것 / 기각한 것

| 접근 | 내용 | 처리 | 근거 |
|---|---|---|---|
| MCD 접근 | 9특징 + MCD, 전류 사인 맞춤 | **채택** (통합 관점) | 주입 고장 재현율 62%(M1) → 전류 관점 추가 후 71% |
| MCD 접근 | 조각 길이별 윈도우, 1샘플 튐 보정 | **채택** | 짧은 조각까지 판정, 튐 경보 감소 |
| 형상·검증 접근 | OOF 정상 분포 기반 보정, 정상 백분위 출력 | **채택** (모든 모델 공통) | 모델 간 공정 비교, 희귀도로 설명 가능 |
| 형상·검증 접근 | 시간 블록·순방향 분할, 반증 점검(이득, 섞기, 순환 이동), 메타데이터 감사 | **채택** (평가 설계) | 7.2, 7.4절 |
| 형상·검증 접근 | 2단계 경보(주의/경고), 스트림 지표(시간당 에피소드) | **채택** | 7.5절 |
| 형상·검증 접근 | 형상(z-정규화 파형) + 스펙트럼 형상 탐지기 | **기각** (비교 기준 B4로만) | 오경보 1% 보정 시 주입 고장 22%, 1샘플 튐에 82% 경보. 진폭을 정규화로 지워 진동 크기 증가, 전류 중심선/진폭 변화를 원리상 못 봄 |
| 형상·검증 접근 | 경고 = 두 관점 모두 q99 (AND) | **기각** (B4′) | 오경보 0%이지만 주입 고장 4.5% |
| 추가 | 견고한 임계값 보정 | **추가** | 라벨이 사람 판단이라 정상에 고장이 섞일 수 있음 (7.6절) |

## 5. 평가 설계

- **프로토콜** (정상 조각을 나눈 뒤 윈도우를 자른다)
  - 무작위 조각 5-fold × 2 seed: 주 비교.
  - 시간 블록 5개: 연속 구간을 통째로 빼고, 스트림 평가에도 쓴다.
  - 순방향: 앞 80%로 학습하고 뒤 20%로 시험한다. 저부하 구간이 시험에만 나온다.
- **시험 세트**
  - 남겨 둔 정상 조각: 오경보.
  - 실제 이상 21조각.
  - 주입 고장 11종: 남겨 둔 16행 이상 조각에 주입하고, 깨끗한 원본과 1:1로 둔다.
  - 1샘플 전류 튐: 경보하면 안 되는 방해 요인.
- **지표**
  - 조각 단위: 오경보율, 재현율, 정밀도, F1, ROC-AUC, PR-AUC, 혼동행렬.
  - 스트림: 경보 조각 비율, 시간당 경보 에피소드, 최대 연속 오경보.
  - 조기 탐지: 고장이 서서히 커질 때 첫 경보 시점의 고장 크기, 갑작스러운 이상의 탐지 지연.
- **판정 기준은 "경고" 단계**다.
  - 실제 이상은 모든 좋은 모델이 100% 잡는다(ROC-AUC ≈ 0.998). 그래서 모델 간 차이는 **주입 고장 재현율**에서 난다.

## 6. 비교 모델

| 기호 | 모델 |
|---|---|
| B0 | 진동 RMS 규칙 (상/하부 RMS z 최댓값) |
| B1 | Isolation Forest (9특징) |
| B2 | kNN 거리 (9특징) |
| B3 | 진동 오토인코더 (16행 원파형) |
| B4 / B4′ | 형상+스펙트럼안 (max 융합으로 1% 보정 / 원래 AND 규칙) |
| M1 | 9특징 MCD 하나 |
| M2 | M1 + 전류 전용 MCD (2관점) |
| M3 | M2의 통합 관점을 GMM 3성분(운전 상태 혼합)으로 |
| **최종** | **M2 + 견고한 임계값 보정** (정상 데이터에서는 M2와 결과 동일) |
