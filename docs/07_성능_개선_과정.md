# 성능 개선 과정

> 모델을 키운 것이 아니라 **오경보의 원인을 찾고 임계값을 정직하게 재는 일**이 성능을 만들었습니다. 단계마다 바꾼 것, 이유, 결과를 정리했습니다. 수치는 모두 이 저장소의 `results/`에서 다시 만들 수 있는 값이고, 그렇지 않은 값은 표시했습니다. 절 번호(7.1절 등)는 [03_결과](03_결과.md)를 가리킵니다.

## 먼저 알아둘 개념 4가지

1. **Mahalanobis 거리**: 정상 데이터의 중심에서 얼마나 떨어졌는지를, 특징 간 상관과 크기 차이를 반영해 잽니다. 상부·하부 RMS가 평소에 함께 움직이는데 한쪽만 오르면, 각 값이 정상 범위여도 거리는 크게 나옵니다.

   `d²(x) = (x − μ)ᵀ Σ⁻¹ (x − μ)`

2. **MCD(Minimum Covariance Determinant)**: 일반 평균·공분산은 이상치 몇 개에 끌려갑니다. MCD는 가장 모여 있는 90%(`support_fraction=0.9`)만으로 중심과 공분산을 추정해서, '정상'에 섞인 이상한 조각에 덜 흔들립니다.
3. **OOF(out-of-fold) 점수**: 학습 조각을 5등분해, 각 조각을 그 조각을 보지 못한 모델로 채점한 점수입니다. 모델은 자기가 본 데이터에 낮은 점수를 주므로, 학습 점수로 임계값을 잡으면 실제 운영에서 오경보가 더 납니다.
4. **고장 주입 평가**: 실제 이상이 21조각뿐이라, 정상 조각에 고장 모양(진동 증가, 충격, 극성 반전, 전류 이동·진폭·왜곡 등)을 강도별로 가해 시험 세트를 만들었습니다(`faults.py`). 주입 고장 재현율은 이 11종의 평균입니다.

## 단계별 상세

### 1. 출발점: 오토인코더가 답이 아니었다

- **상황**: 테스트 데이터와 고장 라벨이 없습니다. 증강과 오토인코더로 개선을 보이는 것이 처음 계획이었습니다.
- **결과**: 같은 평가에서 오토인코더는 주입 고장 10.7%, Isolation Forest는 22.1%로, 단순 진동 RMS 규칙(11.7%)과 비슷했습니다.
- **이유**: 10Hz 데이터에 조각이 짧아(8~24행) 딥러닝이 배울 패턴이 적습니다. 물리적 의미가 있는 소수의 특징을 직접 만들고 통계 모델로 거리를 재는 쪽으로 바꿨습니다.
- **교훈**: 계획한 개선안이 실제로 개선이 아닐 수 있고, 같은 잣대로 비교해야 알 수 있습니다.

### 2. 특징 설계: 신호를 물리적 의미로 압축

- **진동 6개**: 상부·하부 RMS(평균 에너지), 피크(충격), 합 RMS(같은 방향 흔들림), 차 RMS(상·하부가 다르게 흔들림). 합과 차는 위상·극성 같은 '관계의 변화'를 잡습니다.
- **전류 3개**: 전류는 0.6Hz 주기 파형이라 윈도우마다 사인을 맞춰 **중심선**(오프셋), **진폭**, **잔차비**(사인으로 설명 안 되는 비율, 즉 파형 왜곡)를 뽑습니다.
- **결과**: 9특징 MCD 하나(M1)가 주입 고장 62.1%를 잡았고, 이후 단계에서 70.6%까지 올랐습니다.

### 3. 한 샘플 튐 보정

- **상황**: 전류에 한 샘플만 튀는 값이 가끔 있고, 하나만 튀어도 사인 맞춤이 틀어져 잔차비가 커져 경보가 울립니다.
- **1차 시도**: 윈도우마다 잔차가 강건 표준편차(MAD×1.4826)의 4배를 넘는 샘플을 최대 2개까지 맞춤값으로 바꾸고 다시 맞춥니다. 이것만으로는 정상 조각의 19%가 경고됐습니다. 같은 튐이 겹치는 윈도우 일부에서만 복원되어 특징이 어긋났기 때문입니다.
- **개선**: 조각 전체의 윈도우가 "어느 샘플이 튐인가"에 투표하고, 절반 이상이 같은 샘플을 지목하면 조각 전체에서 한 번 복원합니다(`segment_glitch_repair`). 파형이 전체적으로 찌그러진 경우는 샘플 하나로 설명되지 않아 건드리지 않습니다.
- **결과**: 1샘플 튐(진폭의 0.5배) 경고 19.4% → 2.5%, 오경보·재현율은 그대로입니다. 형상+스펙트럼 탐지기는 82%였습니다. 더 작은 튐(0.25배) 36%, 튐 2개 34%는 남은 약점입니다.

### 4. 저부하 오경보의 원인 찾기

- **상황**: 현장에서 부하가 바뀔 때마다 경보가 울리면 작업자는 경보를 무시하게 됩니다.
- **원인 추적**: MCD 점수는 특징별 기여도(`zᵢ × (Σ⁻¹z)ᵢ`, 합하면 점수)로 분해됩니다. 오경보 조각은 상부·하부 상관이 대부분을 차지했습니다. 저부하에서는 진동이 작아 상관의 부호가 뒤집힙니다.
- **조치**: 상관 특징을 빼고, '상·하부 관계'는 합 RMS와 차 RMS가 맡게 했습니다.
- **의미**: 모델을 바꾸지 않고 오류의 원인을 특징 단위로 해부해 해결했습니다. 설명 가능한 모델을 고른 이유가 여기서 드러납니다.

### 5. 길이별 윈도우

- 조각 길이가 제각각이라 24행 윈도우로 고정하면 짧은 조각은 판정할 수 없고, 8행으로 고정하면 긴 조각의 특징이 불안정합니다.
- 24행 이상은 24행, 16~23행은 16행, 8~15행은 8행 윈도우(4행 간격)를 쓰고, **길이마다 모델을 따로** 학습합니다. 조각 점수는 윈도우 점수의 평균입니다.
- 8행 미만은 특징을 믿을 수 없어, 시간상 가장 가까운 판정 조각의 결과를 따릅니다(`fill_short`).
- 길이를 섞어 한 모델로 학습하면 안 되는 이유는 [05_노트북_비교_및_튐_복원](05_노트북_비교_및_튐_복원.md)의 10.1절에서 실험으로 확인했습니다. 8행 윈도우의 점수가 24행보다 30배 커서, 하나의 경고 선이 긴 조각을 놓칩니다.

### 6. OOF 임계값: 오경보를 정직하게 재기

- 학습에 쓴 조각의 점수로 q99를 잡으면 모델이 그 조각에 익숙해 임계값이 낮게 잡히고, 새 데이터에서는 목표(1%)보다 오경보가 많아집니다.
- 5-fold OOF 점수의 q99를 경고, q95를 주의로 씁니다.
- **검증을 세 번 한 이유**: 무작위 분할만 하면 인접 시간대의 비슷한 조각이 학습·검증에 나뉘어 성능이 부풀려집니다. 시간 블록 분할과 과거로 학습해 미래를 평가하는 순방향 분할을 함께 돌렸습니다.
- **결과**: 오경보 1.3% / 1.7% / 0.8%(무작위 / 시간 블록 / 순방향). 목표 1% 근처가 세 분할에서 모두 유지됩니다.

### 7. 두 관점 융합: 약한 전류 고장 살리기

- 통합 모델에서 전류 특징은 3개뿐이라, 전류만 살짝 변하는 고장은 진동 6개의 정상 값에 묻힙니다.
- 통합 9특징 모델과 전류 전용 3특징 모델을 둘 다 돌리고, 각 점수를 정상 백분위로 바꿔 큰 쪽(max)을 씁니다. 두 모델의 점수는 특징 수가 달라 크기가 다르기 때문에 백분위로 맞춥니다. 출력도 "정상 중 상위 몇 %"로 현장에서 읽기 쉽습니다.
- **AND 규칙은 기각**: 둘 다 넘어야 경고하면 한쪽만 변하는 고장을 놓쳐 주입 고장 4.5%만 잡았습니다.
- **결과**: 주입 고장 62.1% → 70.6%, F1 0.79.
- **원인 진단**: 진동 전용·전류 전용 점수를 카이제곱 꼬리확률로 바꿔(자유도 6, 3) 둘 다 1/1000 미만이면 복합형, 아니면 더 희귀한 쪽을 진동형/전류형으로 냅니다. 진동 고장의 99.8%가 진동형, 전류 고장의 95.7%가 전류형으로 나옵니다.

### 8. 라벨 오염 방어: 스스로 세운 가정을 반증하다

- **상황**: "정상 라벨에 초기 고장이 섞여도 MCD는 유지된다"는 가정이 있었는데, 다시 재 보니 틀렸습니다. MCD 자체는 버텨도 **임계값이 오염된 점수로 계산되어** 올라가고, 오염 2%만으로 같은 고장 재현율이 32%로 떨어졌습니다.
- **조치**: OOF 점수의 로그에서 강건 z(중앙값·MAD 기준)가 3.5를 넘는 조각을 임계값 계산에서 뺍니다.
- **결과**: 오염 2% / 5% / 10%에서 재현율 91% / 81% / 47%. 현재 정상 데이터에서는 제외되는 조각이 0이라 깨끗한 데이터의 성능 손해가 없습니다.
- **M3와의 비교**: GMM 3성분 상태 혼합(M3)은 깨끗한 데이터에서 74.9%로 더 높지만, 같은 보정을 붙여도 오염 2% / 5% / 10%에서 73% / 30% / 11%로 무너집니다. GMM이 섞인 고장을 "정상의 한 상태"로 배워 버리기 때문입니다. 정상 라벨을 믿기 어렵다면 최종 모델(M2 구조)이 더 안전합니다.

### 9. 스트림 경보: 점진 고장을 일찍, 경보는 덜 자주

- 조각 하나씩 판정하면 천천히 커지는 고장은 한참 뒤에야 임계값을 넘고, 임계값을 낮추면 경보가 잦아집니다.
- 엄격 단일(q99.7)은 한 번에 큰 이상을 잡고, EWMA는 최근 점수에 가중을 둔 이동평균이라 작은 이탈이 쌓일 때 잡습니다. 둘을 OR로 결합하고 정상 스트림에서 함께 1%로 맞췄습니다.

  `Eₜ = λ·sₜ + (1 − λ)·Eₜ₋₁,  λ = 0.2`  (sₜ: t번째 조각의 점수, Eₜ가 임계를 넘으면 경보)

- **결과**: 정상 스트림에서 시간당 경보 에피소드 7.1 → 3.1, 점진 고장의 첫 경보는 진동 ×1.24, 전류 중심선 +1.04에서 나고 고장 전 오경보는 0회입니다.

## 남은 과제

- 저부하 진동 ×1.5, 하부 진동 극성 반전은 거의 못 잡습니다(극성 반전 36%, 저부하에서는 0%).
- 센서 이득 ×1.1에 12%, ×1.2에 37%가 경고됩니다. 센서 교정과 실제 진폭 증가를 이 데이터만으로 구분할 수 없습니다.
- 라벨 오염 10%에서는 재현율이 47%로 떨어집니다.
- 데이터 한계: 10Hz라 0~5Hz만 관측, 실제 이상은 하루치 21조각, 주입 고장의 모양·크기는 가정, 정상·이상 기록이 5일 떨어져 있습니다.
- 팀 논의 사항: M2(라벨 오염에 강함)와 M3(깨끗한 데이터에서 더 높음) 중 최종 선택, 1차 경보 규칙(q99 단일 vs 엄격+EWMA).
