### 10.1 원인 확인 실험 (`results/notebook_compare/variants/`)

노트북 최종 모델에 두 가지만 바꿔서 같은 시험을 다시 돌렸다. 다른 것은 그대로다.
모델은 "하나로 섞음(pooled)"과 "윈도우 길이별로 나눔(split)", 경고 선은 "노트북 방식(보정 구간 윈도우 q99)", "OOF 하나(oof_global)", "OOF 길이별(oof_route)"이다.

| 모델 / 경고 선 | 정상 오경고 | 주입 고장 11종 경고율 | 노트북 교란 5종 경고율 |
|---|---|---|---|
| 섞음 / 노트북 (원래) | 3/114 | 0% | 46% |
| 섞음 / OOF 하나 | 3/114 | 0% | 46% |
| 섞음 / OOF 길이별 | 1/114 | 53% | 77% |
| 나눔 / 노트북 | 1/114 | 52% | 79% |
| 나눔 / OOF 하나 | 1/114 | 39% | 76% |
| 나눔 / OOF 길이별 | 1/114 | 49% | 77% |
| 참고: 우리 M1 / 우리 최종 | 1/114 / 2/114 | 51% / 68% | 66% / 77% |

- 둘 중 하나만 고치면 된다. 모델을 길이별로 나누거나, 경고 선을 길이별로 따로 두면 노트북의 0%가 약 50%로 올라간다. 오경고도 3건에서 1건으로 준다.
- 경고 선을 어떻게 구하든(보정 구간이든 OOF든) 선이 하나뿐이면 그대로 0%다. 길이를 구분하지 않은 것이 원인이다.
- 고친 노트북 모델은 우리 M1(9특징 하나)과 같은 수준이다. 우리 최종이 앞서는 부분은 전류 전용 관점이다. 전류 진폭 ×1.2, ×1.3, 파형 왜곡 0.05에서 노트북 쪽은 4%, 13%, 10%, 우리는 38%, 81%, 95%다.
- 같은 이유로 센서 이득 ×1.2에 우리가 더 민감하다(30% 대 1~3%). 전류가 20% 커지는 것을 전류 관점이 진폭 증가로 읽기 때문이다. 센서 교정 변화와 실제 진폭 증가는 이 데이터만으로 구분할 수 없다.

### 10.2 노트북의 아이디어를 우리 모델에 하나씩 넣어 본 결과 (`python -m kamp.port`, `tables/16`)

우리 최종 구조에 한 번에 하나씩만 바꿔서, 무작위 5-fold(seed 0)로 비교했다. 차이는 기준(P0) 대비 폴드별 짝지은 차이의 평균 ± 표준오차다.

| 바꾼 것 (노트북 방식) | 오경보율 | 주입 고장 재현율 | 1샘플 튐 경보 | 판정 |
|---|---|---|---|---|
| P0 기준 (우리 최종) | 1.5% | 71.0% | 19.4% | |
| P1 구간 점수 = 윈도우 최댓값 | +0.2 ± 0.6 | +0.1 ± 1.3 | **+16.9 ± 1.7** | 기각 |
| P2 구간 점수 = 상위 2개 평균 | +0.2 ± 0.7 | +0.3 ± 1.4 | **+13.1 ± 1.6** | 기각 |
| P3 MCD 지지 비율 0.75 | −0.7 ± 0.3 | **−2.3 ± 0.7** | −1.3 ± 1.0 | 기각 (오경보를 줄인 만큼 재현율도 준다) |
| P4 로버스트 스케일러 | 0 | 0 | 0 | 효과 없음 |
| P5 전류 왜곡 = 절대 잔차 | −0.3 ± 0.5 | **−4.7 ± 1.2** | −2.1 ± 1.4 | 기각 |
| P6 윈도우 50% 겹침 | 0 | **−3.5 ± 0.5** | −7.2 ± 0.5 | 기각 |

- 노트북의 모델 쪽 아이디어 중에 우리 모델을 좋게 만드는 것은 없었다. 고장 재현율이 오른 항목이 없고, 최댓값/상위 2개 평균은 1샘플 튐 경보만 늘린다.
- P4가 정확히 0인 것은 당연하다. MCD는 척도를 바꿔도 거리가 변하지 않는다(아핀 불변).
- P3의 오경보 0.8%, 재현율 68.7%는 임계값 곡선의 q99.5(0.8%, 67.1%)보다 1.6%p 좋을 뿐이라, 효과는 임계값을 조금 올린 것과 비슷하다.
- 노트북에서 가져올 만한 것은 모델이 아니라 **평가 방식**이다(10절 앞부분: 시간순 분할 시험, 반증 점검, 구간 길이별 판정 확인). 이미 평가 코드에 반영했다.

## 11. 1샘플 튐 경보 줄이기 (`python -m kamp.glitch_fix`, `tables/17`)

문제: 전류 신호의 샘플 하나가 진폭의 0.5배만큼 튀면 정상 조각의 19%가 경고됐다. 짧은 조각(16~23행)에서는 46%였다.
원인은 윈도우마다 따로 복원하기 때문이다. 같은 튐이 겹치는 윈도우 중 일부에서는 복원되고 일부에서는 남아서, 전류 특징이 조금 어긋난다.
전류 관점이 정상에서 매우 규칙적이라 이 작은 어긋남에도 경고한다.

한 번에 하나씩 바꿔서 무작위 5-fold(seed 0)로 비교했다. 튐 열은 모두 "정상 조각에 튐을 넣었을 때 경고하는 비율"이다(낮을수록 좋다).

| 튐 복원 방식 | 오경보율 | 주입 고장 재현율 | 튐 0.5배 | 튐 0.25배 | 튐 2개 |
|---|---|---|---|---|---|
| G0 기준: 잔차 4σ 넘는 샘플 2개까지 | 1.5% | 71.0% | 19.4% | 43.7% | 60.0% |
| G1 하나 빼기 복원 τ=0.5 | 3.2% | 68.0% | 3.6% | 15.8% | 40.2% |
| G2 하나 빼기 복원 τ=0.3 | 1.5% | 71.0% | 6.1% | 48.6% | 74.2% |
| G3 하나 빼기 복원 τ=0.15 | 1.2% | 70.7% | 48.3% | 71.1% | 85.2% |
| G4 하나 빼기 + 4σ 규칙 (τ=0.3) | 1.5% | 71.0% | 3.2% | 37.2% | 49.4% |
| G5 조각 전체 합의 + 4σ 규칙 | 1.3% | 70.7% | 2.5% | 35.5% | 36.1% |
| **G6 조각 전체 합의 + 하나 빼기 + 4σ 규칙 (채택)** | 1.5% | 71.0% | **2.5%** | 36.0% | **33.8%** |

- **하나 빼기 복원:** 윈도우의 샘플 하나를 뺐을 때 잔차 제곱합이 τ 아래로 떨어지면 그 샘플이 튐이다. 파형이 전체적으로 찌그러진 경우에는 샘플 하나로 설명되지 않아서 건드리지 않는다.
- **조각 전체 합의:** 조각 안의 모든 윈도우가 "어느 샘플이 튐인가"에 투표하고, 그 샘플을 포함한 윈도우의 절반 이상이 같은 샘플을 지목하면 조각 전체에서 한 번 복원한다.
- τ를 키우면(G1) 정상 윈도우도 건드려서 오경보와 전류 고장 재현율이 나빠진다. τ를 줄이면(G3) 튐을 놓친다.
- G6은 고장별 재현율이 기준과 소수점 셋째 자리까지 같다(진동 ×1.5 39.2%, 전류 진폭 ×1.2 38.5%, 파형 왜곡 0.05 89.0% 등).
- 최종 모델에 반영한 뒤 전체 평가를 다시 돌린 결과(튐 경보율): 무작위 5-fold×2는 20.6% → 2.5%, 시간 블록 22.6% → 3.4%, 순방향 13.5% → 3.1%.
  - 오경보율, 실제 이상 재현율, 주입 고장 재현율은 그대로다(블록의 주입 고장 72.60% → 72.64%).
  - 원본 두 파일의 예측은 정상 조각 599개 중 2개만 단계가 바뀌었고(주의 ↔ 정상), 실제 이상 21개는 모두 그대로 경고다.

**남은 한계와 비용**
- **작은 튐:** 진폭 0.25배 이하의 튐은 아직 36%가 경고한다. 이 크기는 정상 파형의 흔들림(진폭의 약 4~5%)과 겹쳐서 윈도우 하나만 보고는 구분되지 않는다.
- **추세 규칙:** 정상 스트림에서 엄격 단일+EWMA 규칙의 경보가 1.1% → 1.3%(시간당 에피소드 2.4 → 3.1)로 조금 늘었다. 조각 1개 수준의 차이라 잡음일 수 있지만 보고한다.
- **노트북 시험 분할:** 앞 60%(359조각)만으로 학습한 시험에서 정상 오경고가 1/114 → 2/114로 한 건 늘었다(10절 표에 반영). 학습이 적을 때 임계값이 불안정할 수 있다는 신호이지만, 한 건이라 확정할 수는 없다.
