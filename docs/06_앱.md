## 12. 분석·모니터링 앱 (`streamlit run app.py`)

상단 메뉴에 화면이 두 개 있다.

```bash
pip install -r requirements.txt
streamlit run app.py          # 모니터링 시연은 처음 실행 때 대시보드용 모델을 학습한다 (~1분)
python -m kamp.dashboard_core build      # 대시보드용 모델 다시 학습
python -m kamp.dashboard_core simulate   # 정지 규칙 점검 -> results/raw/dashboard_stop_rule.csv
```

**파일 분석** (`views/analysis.py`, 계산은 `src/kamp/analysis.py`, `run.py predict`와 같은 코드)

1. 데이터 선택: CSV 업로드 또는 대회 제공 파일 버튼. 필수 열이 없거나 분석 가능한 행이 8개 미만이면 이유를 보여 주고 이 단계에 머문다.
2. 데이터 확인: 전체 행, 분석 대상 행(중복·제외 행 수와 예시 index), 조각 수, 미리보기.
3. 분석: 진행 상태 표시.
4. 결과
   - 요약: 판정 문장, 전체 행, 정상·주의·경고 조각 수(행 수 함께), 경고 비율, 판정 기준.
   - 신호와 판정: 조각별 희귀도 + 상부 진동·하부 진동·전류. 가로축은 측정 시각 또는 원본 index. 모든 샘플을 실제 위치에 그리고, 측정 공백에서는 선을 끊는다. 색은 조각 판정(정상·주의·경고), 속이 빈 점은 8행 미만이라 이웃 조각 판정을 따른 조각.
   - 이상 조각 표: 조각, 원본 index 범위, 시각, 행 수, 판정, 희귀도, 이상 거리(통합 MCD 거리², 정상 99% 지점과 비교), 신호 유형, 주요 특징, 판정 근거. 이상이 없으면 그 사실과 희귀도가 가장 높은 5개를 보여 준다.
   - 조각 상세: 선택한 조각의 원신호(앞뒤 조각은 회색), 관점별 희귀도, 특징 기여 비중.
   - 행별 데이터와 CSV 내려받기: 입력 행 전부가 결과에 남는다.

**모니터링 시연** (`views/monitor.py`)

- 상단 조작부: 시나리오, 정지 조건 K, 재생 간격, 자동 정지, 정답 표시, 재생·한 조각·처음부터·정지 해제. 시나리오 구성(몇 번째 조각부터 이상인지)을 함께 보여 준다.
- 상태 요약: 현재 단계(정지 요청이면 조각 번호와 이유), 프레스 상태, 현재 조각 희귀도, 진행, 경보 기록 수.
- 실시간 신호: 최근 40초 분량. 가로축은 재생 시간(초)이며 샘플 간격은 실제 0.1초 그대로, 조각 사이 공백만 0.6초로 압축한다. 조각마다 번갈아 음영을 깔고 위에 조각 번호를 적어, 가로 폭이 곧 실제 측정 길이(1~50행 = 0.1~5초)로 보인다. 8행 미만이라 판정하지 않은 조각은 회색 점선(판정 보류).
- 조각별 희귀도: 주의·경고 기준선, 추세(EWMA)와 한계, 이상 구간(정답 표시 시), 정지 요청 시점.
- 원인 진단, 경보 기록, 성능 요약과 한계(접이식).

**시나리오 8개:** 정상 운전, 실제 이상 기록, 진동 점진 증가, 전류 중심선 점진 이동, 전류 진폭 점진 증가, 충격 스파이크 돌발, 하부 진동 극성 반전, 전류 1샘플 튐(센서 노이즈)

**정지 규칙.** 조각이 하나 끝날 때마다 판정한다. 경고가 K조각 연속이거나 추세 경보(단일 q99.7 초과 또는 EWMA 한계 초과)가 K조각 연속이면 정지를 요청한다. 기본 K=2이고 상단 조작부에서 1~3으로 바꿀 수 있다. 8행 미만 조각은 이전 상태를 유지하고 횟수에 세지 않는다. 정지 신호는 시연용 출력이며 어떤 설비에도 연결되어 있지 않다.

**시연의 공정성.** 앱이 쓰는 모델은 정상 조각 중 시간상 앞 80%(479개)로만 학습한 별도 모델이다. 재생하는 정상 구간은 학습에 쓰지 않은 뒤 20%(120개), 이상은 실제 이상 21조각과 그 구간에 주입한 합성 고장이다. 새 파일 예측에 쓰는 `models/final_system.pkl`(전체 정상 데이터로 학습)과는 다르다.

**정지 규칙 점검** (`results/raw/dashboard_stop_rule.csv`, 주입 시나리오는 시드 5개, 고장 시작 후 정지까지 조각 수의 중앙값)

| 시나리오 | K=1 | K=2 (기본) | K=3 |
|---|---|---|---|
| 정상 운전 120조각 | 오정지 있음 | 오정지 0 | 오정지 0 |
| 전류 1샘플 튐 | 5개 중 3개에서 오정지 | 오정지 0 | 오정지 0 |
| 실제 이상 기록 | 1조각 | 2조각 | 3조각 |
| 충격 스파이크 돌발 | 0조각 | 1조각 | 2조각 |
| 전류 중심선 점진 이동 | 0조각 | 1조각 | 2조각 |
| 전류 진폭 점진 증가 | 6조각 | 7조각 | 8조각 |
| 진동 점진 증가 (1.1→2.0배, 30조각) | 20조각 | 21조각 | 28조각 |
| 하부 진동 극성 반전 | 정지 못함 | 정지 못함 | 정지 못함 |

- K=1은 경고가 한 번만 떠도 정지시켜서 정상 구간과 센서 노이즈에서 오정지가 난다. K=2부터 오정지가 사라지고 고장 탐지는 조각 하나만 늦어진다.
- 진동 점진 증가에서는 정지 요청(21조각 후, 진동 약 1.7배)이 첫 경고(35조각 후)보다 먼저 나온다. 추세 경보 경로가 서서히 커지는 변화를 먼저 잡기 때문이다.
- 하부 진동 극성 반전은 8절의 알려진 약점(저부하 상태에서 놓침) 그대로 정지하지 못한다.

**한계**

- 정지 신호는 시연용이다. 실제 적용에는 현장 안전 절차와 오정지 비용(생산 손실)에 맞춘 K, 임계값 재검토가 필요하다.
- 조각이 끝나야 판정하므로 최대 조각 길이(5초)만큼 지연이 있고, 조각 사이에는 공백이 있다. 실시간 센서 연결은 구현하지 않았다.
- 오정지 점검은 미학습 정상 120조각(약 15분)과 시드 5개 기준이라 표본이 작다. 정상 데이터는 76분, 이상 기록은 하루치다.
- 주입 고장의 모양과 크기는 가정이다. 시연 정답 표시는 실제 설비에는 없는 정보다.
