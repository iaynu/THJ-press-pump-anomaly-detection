> 상세 설명서의 0절, 1절, 2절. 절 번호는 원본 그대로이고, 요약은 [README](../README.md)에 있습니다. 경로는 저장소 루트 기준입니다.

## 0. 제출물 구성 (대회 요구 항목 대응)

| 요구 항목 | 위치 | 비고 |
|---|---|---|
| 소스코드 | `run.py`, `app.py`, `src/kamp/`, `views/` | 진입점은 `run.py` (train / predict / evaluate / all) |
| 환경 파일 | `requirements.txt` | Python 3.13 검증, 버전 고정 |
| 학습용 데이터 | `data/press_data_normal.csv`, `data/outlier_data.csv` | 대회 제공 원본 그대로. 최종 모델은 정상 파일 599조각 전체로 학습 |
| README | 이 문서 | 실행 방법 2절, 결과 7절 |
| 테스트데이터 예측결과 | `results/predictions_outlier_data.csv`, `results/predictions_press_data_normal.csv` | 행 단위 예측(입력 행 모두 보존, 열 설명 2절) |
| (교차검증 예측) | `results/raw/random_segments.csv`, `blocks_segments.csv`, `forward_segments.csv` | 학습에 쓰지 않은 조각에 대한 조각 단위 예측. 혼동행렬은 `results/tables/04_*` |
| 학습된 모델 | `models/final_system.pkl` (제출 모델), `models/dashboard_system.pkl` (시연용, 앞 80% 학습) | `run.py train`으로 다시 만든다 |
| 실행 기록 | `results/logs/` | 2026-10-08 재실행 로그 포함 |

대회에서 별도 테스트 파일이 제공되지 않아, 제공 이상 기록(`outlier_data.csv`)과 교차검증의 시험 조각을 테스트데이터로 사용했다.
새 CSV는 `python run.py predict --input <파일>`로 같은 형식의 예측 파일을 만든다.

**최종 모델 = 두 관점 MCD(통합 9특징 + 전류 전용 3특징) + max 융합 + 견고한 임계값 보정(z>3.5) + 조각 전체 합의 튐 복원**

- 오경보율 1.3%(무작위 5-fold×2) / 1.7%(시간 블록) / 0.8%(순방향)
- 실제 이상 21조각 재현율 100%(모든 프로토콜)
- 주입 고장 11종 평균 재현율 71%, F1 0.79
- 1샘플 전류 튐에 경고하는 비율 2.5%(복원 도입 전 20.6%)
- 분석·모니터링 앱(`streamlit run app.py`): CSV 업로드 → 확인 → 분석 → 결과·이상 조각 목록·조각 상세, 그리고 2단계 경보와 연속 조건 정지 요청을 재생하는 모니터링 시연 (12절)
- 같은 오경보 수준에서 형상+스펙트럼안은 22%, 진동 RMS 규칙은 12%다.

## 2. 실행

```bash
pip install -r requirements.txt
python run.py train                                   # 정상 데이터 전체로 최종 모델 학습 (~30초)
python run.py predict --input data/outlier_data.csv   # -> results/predictions_outlier_data.csv
python run.py evaluate                                # 모든 실험 + 표/그림 (~60분, 2코어 기준)
```

입력 CSV 형식은 대회 파일과 같다(index, TimeStamp, AI0_Vibration, AI1_Vibration, AI2_Current; Equipment_state는 없어도 된다).
날짜, 시각, 공백 길이는 모델 입력으로 쓰지 않는다. 시각은 조각을 나누는 데에만 쓴다.

예측 파일의 열은 다음과 같다.

| 열 | 뜻 |
|---|---|
| row_status | 분석 / 중복 행(시각·센서 값이 같은 앞 행의 결과를 그대로 붙임) / 제외(결측·숫자 아님·시각 오류, 결과 없음). 입력 행은 모두 결과 파일에 남는다 |
| segment_id, segment_rows | 행이 속한 조각, 조각 길이 |
| judged_directly | 조각이 8행 이상이라 직접 판정했는가 (아니면 시간상 가장 가까운 조각의 판정을 따름) |
| p_joint, p_current | 각 관점의 정상 백분위 (정상 OOF 점수 중 이보다 낮은 비율) |
| normal_percentile, rarity_1_minus_p | 두 관점 중 큰 값, 희귀도 1−p (고장 확률이 아니라 "정상 중 이만큼 드물다") |
| level, level_name | 0 정상 / 1 주의(q95) / 2 경고(q99) |
| trend_warning | 추세 규칙: 엄격 단일(q99.7) 또는 EWMA(λ=0.2) |
| pred_label | 경고=1 |
| diagnosis | 진동형 / 전류형 / 복합형 (경보 조각만) |

원본 파일 예측 결과:
- outlier_data: 21조각 모두 경고. 진단은 복합형 16, 전류형 2, 이웃 조각 판정 따름 3이다.
- press_data_normal(학습 데이터 자체): 경고 4조각(0.7%), 주의 25조각이다. 20,000행 중 index 11565는 11564와 시각·값이 완전히 같은 중복 행이라 한 번만 분석하고, 결과 파일에는 11564의 판정을 붙여 20,000행 모두 남긴다.
